# Survivability validation — Brutoh, Magisters' Terrace +12, 2026-05-15

Log: `examples/WoWCombatLog-051526_210245.txt`
Run: Magisters' Terrace +12 Tyrannical, 28m32s, **timed** (success=True)
Group: shaman healer (Player 1, Earth Shield on tank)

## Ground truth (from log)

- **3 deaths** at t=897.6s, t=1451.8s, t=1498.9s (after pull start)
- Total damage taken to HP: **34,567,826** (DTPS post-mit = 20,196)
- Total base damage: 267,901,495
- Overall mitigation: **87.10%**
- Top fatal-window damage: shadow-school casts (Shadow Bolt, Umbral Splinters, Consuming Shadows, Void Destruction)

Brutoh's HP in log: 768,174 (yaml = 751,872, +2.2% drift — within noise)

## What was tested

**The log-replay path**, not the predictive path:
- MGT is not in `dungeons.yaml`, so simf cannot generate a synthetic profile for this dungeon
- Instead, the actual damage events from the log were fed through the engine via `events_override` (events fixed, RNG only governs block/parry/crit-block rolls)
- The mitigation engine math + the policy heuristics are what was validated; the predictive event-generator was not

## Result

### Death prediction — directionally correct

With the `m+_high_key_healer` profile (reactive bursts + DR cooldowns) and `baseline_hps = 1.1× log DTPS`:

- Sim death rate: **100% (50/50 iterations)** — at deterministic t=888s
- Log: first death at t=897s — **9-second alignment** with the sim's predicted spike
- The sim correctly identifies the large pull around t=15min as the killer spike

**Caveat on "100% death rate":** with `events_override` the damage stream is fixed across iterations — RNG only varies block/parry rolls. So "100%" is not a Monte Carlo probability. It is "given this exact sequence of events and simf's policy heuristics for Shield Block / Shield Wall / Ignore Pain, no plausible avoidance-roll sequence saves Brutoh at t=888s." The reader should not update this into "MGT +12 = certain death".

### DTPS — sim runs +10% high (with healer model), +27% high (raw mitigation)

| Scenario | DTPS | Delta vs log |
|---|---|---|
| Log actual | 20,196 | — |
| Raw replay (single iter, no healer) | 25,683 | +27% |
| Full healer profile (50 iter mean) | 22,203 | +10% |

The 10–27% over-prediction is driven entirely by **magic-school under-mitigation** (see next).

### Per-school mitigation — physical is right, magic is systematically under-mitigated

Single-iteration replay (events fixed, mitigation re-applied):

| Ability | School | Log mit% | Sim mit% | Δ |
|---|---|---|---|---|
| auto-attack | physical | 92.7 | 91.3 | **−1.4 pp** |
| Entropy Blast | physical | 94.0 | 83.7 | −10.3 pp |
| Shadow Bolt | shadow | 58.8 | 47.8 | −10.9 pp |
| Umbral Splinters | shadow | 61.8 | 38.3 | **−23.5 pp** |
| Void Destruction | shadow | 65.4 | 33.7 | **−31.7 pp** |
| Consuming Shadows | shadow | 60.9 | 52.7 | −8.2 pp |
| Devouring Strike | shadow | 72.3 | 56.8 | −15.5 pp |
| **Total (top 20)** | | **87.9** | **84.3** | **−3.6 pp** |

The headline: physical mit is essentially correct (−1.4pp on auto-attack), but **magic schools are under-mitigated by 10–30 percentage points**. Armor-K calibration cannot close this gap; K only touches physical.

Candidate causes for the magic gap (ordered by likelihood):
1. **Active mitigation timing not reproduced.** Brutoh likely Spell-Reflected the Shadow Bolt cast, popped Shield Wall through the burst at the t=897s pull, and timed Ignore Pain. The replay policy makes its own (different) choices.
2. **`log_absorbed` does not capture all Ignore Pain.** The field includes IP + healer shields, but if some IP fired between an event and the next log line, attribution may slip.
3. **Missing 12.0.5 magic-DR effect.** Some passive or boss debuff the engine doesn't model.

## What this means for simf's validity

Three separate claims to make, of varying confidence:

1. **"Did simf flag this run as dangerous?"** — **Yes.** Every iteration produced a death; p99 5s damage window was 1.14M against an 782k HP pool (= 146% max HP). Any reasonable verdict layer reading these numbers would have marked MGT +12 as high-risk for Brutoh's current gear.

2. **"Did simf identify *when* the dangerous moment was?"** — **Yes.** Sim death at t=888s vs log death at t=897s. The engine + policy correctly recognized the t≈15min pull as the spike, not the boss fights or other random pulls.

3. **"Are simf's mitigation numbers right in absolute terms?"** — **Physical: yes** (auto-attack within 1.4pp). **Magic: no, off by 10–30pp.** This is the most actionable finding from this validation and points at how to improve calibration on magic-heavy dungeons.

## Caveats for the predictive path

This validation does not directly test simf's *predictive* survivability score for MGT +12, because:
- MGT is not in `dungeons.yaml` (no school-mix entry, no K calibration note)
- The `m+_high_key_healer` profile is class-agnostic; it does not model shaman-specific tools (Spirit Link Totem, Earth Shield throughput, Riptide HoT)
- The replay only re-mitigates events that already happened — it cannot speak to whether a fresh sim run against a synthetic MGT profile would correctly predict death
